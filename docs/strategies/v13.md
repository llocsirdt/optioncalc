## Intent

[v12](v12.md) plus a safety net: the roster's continuous cover, but **only on a position that has had 30
minutes to be naturally offset** and has not been. Same 8 v6 shapes as v12.

## Open signal

**Identical to v12**: the v6 signal, the ADD gate (NQ 15m outer band, ≤ 3 adds a side), REV reversal-opens
(touch + 30-min speed + 40/60-pt zigzag run, struck at the pair's short, pair + REV ≤ 1.15 W), and the jump guard.

## Cover signal

Everything except the continuous cover is refused as on v12 (`cover-skip-natural`, `trader.js:185-188`: only
`'continuous'` and `'restrike'` cover notes pass for v13). The continuous cover — v6's, at `W − openCost −
minLock` with the ladder, give-up and stall on what it places — is placed only when `v13CoverHold`
(`natural-cover.js:215`) returns null:

| Position | v13 cover |
|---|---|
| offset (its REV filled) | never covered |
| a jump-guard vertical | never covered |
| younger than `coverAfterMin` (30 min since its fill) | waits |
| otherwise | continuous cover placed |

Live: `placeContinuousCovers` (`trader.js:1934-1935`); backtest: `backtest-v6-5m.js:1105` (`continuousCover`
runs under `noPpc` only when `natural === 'v13'`). No signal, proactive or cover-to-stack covers. (`coverToStack: true`
on the roster never fires live — see [v12](v12.md#cover-signal).)
