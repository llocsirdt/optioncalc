# v9 — "be-wrong + caps"

`{ key: 'v9', label: 'be-wrong + caps', signalFn: v7Signal, signalCfg: { fiveMin: true, beWrong: true }, bidirectional: true, proactiveCoverFrac: 0.80, ...PORTED_COVER }`
— `server/src/candle-spread/index.js:186`

## Intent

Take the **v7 signal exactly as it is** and add one mutation: cover any position that reaches
0.80 × width, deeper than v8's 0.70. `index.js:184-185` calls it "the high-ceiling variant. Still
paper pending go/no-go".

Since 2026-09-07, v9's role — like v8's — is an **experiment slot**, not a trading candidate. User's
ruling: *"we want to use those slots to see if we can tweak v6 or v7 rules to beat them, which is
likely why they're so closely correlated."* High correlation with the parent is the *point* of a
mutation slot. **Do not propose retiring v9 on the grounds that it correlates with v7.**

## Open signal

**Identical to [v7](v7.md#open-signal)** — `v7Signal` with `{ fiveMin: true, beWrong: true }` and
`bidirectional: true`. No `at15` wrapper; acts on every 5m bar.

- intra-15m bars: per-side cover on a 2-bar-confirmed 5m structural reversal, flipping only if 15m
  agrees;
- 15m closes: per-side trend-flip → **be-wrong** (open the opposite side without covering the
  underwater one) → overextension reversal → grind → active-cover → gated trend continuation.

There is **no open-side difference at all** between v7 and v9. The daily P&L correlation between them
is **1.00**.

## Cover signal

v7's triggers, plus one:

| Trigger | Condition | Placed | Fills |
|---|---|---|---|
| **proactive** (new) | any uncovered position marking ≥ **0.80 × W** | resting, `W − openCost`, on that bar | when the real mark reaches it |
| be-wrong | places **no cover** (by design) | — | — |
| trend-flip / overextension / grind / active-cover | per side, as v7 | resting, `W − openCost` | same |
| `continuous` (shared) | every 5m bar, unarmed → at birth, target `W − openCost − 0.20×W` | | same |
| `lock` (shared) | governor cover-to-continue | `W − openCost` | same |

## Trend / reversal recognition

Identical to v7: per-side held state, structural trend = 15m close + 15m 9EMA vs the 15m midline
(`trendTf` default `'15m'`), intra-15m reversal = 5m structural pair against a held side for two
consecutive 5m bars, be-wrong = reversal candle **plus** a break of the prior extreme against the
held side.

`proactiveCoverFrac` is **not** a market read — it is a book-state threshold on how deep in the money
a position has run.

## Open questions / suspected drift

1. **🚨 CONFIRMED DRIFT (shared) — "continuous cover" is not what the user meant.** The
   implementation rests a cover on **every uncovered position on every bar**
   (`backtest-v6-5m.js:560-587`, `trader.js:669-698`) — at birth for an unarmed family. Intent was a
   **ladder**: opening a new position is the trigger to cover a prior one. Implemented only as the
   unwired `opts.coverPriorOnOpen` backtest flag (`backtest-v6-5m.js:855-861`); no live counterpart
   (`trader.js:838-840` remains a placeholder).
   **Specific consequence for v9:** continuous covering claims every position before
   `proactiveCoverFrac 0.80` can, so **the single flag that distinguishes v9 from v7 is largely
   inert** — which is a plausible mechanical explanation for the 1.00 daily correlation. This has not
   been tested; the correlation is currently attributed to the shared signal alone.
2. **CONFIRMED — the roster and the memory disagree about what v9 IS** (family = v7 + proactive 0.80;
   experiments-log lineage table = a standalone mean-reversion backtest). Both are real things in the
   repo; only one is the family.
3. **The slot holds a mutation already known to be at the wrong end of its own sweep.** `0.80` "barely
   fires"; `0.70` was the measured peak, and v8 already occupies 0.70. So v9's mutation is neither the
   best setting of its own knob nor a new axis. Per the slot policy this is exactly when to swap it —
   but no replacement has been proposed.
4. **Intent not documented:** why v9 pairs proactive covering with the *be-wrong* signal specifically
   rather than v6. The label "be-wrong + caps" implies caps plural; only one cap-like flag is set.
5. **Governor status is a stated open item:** `index.js:185` says v9 is "still paper pending go/no-go
   ([[project_daily_risk_tolerance]])" — no go/no-go decision is recorded.
