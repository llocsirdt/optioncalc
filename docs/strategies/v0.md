# v0 — "classic tent"

`{ key: 'v0', label: 'classic tent', signalFn: at15(classicSignal), signalCfg: {}, coverSelector: 'fixed', coverFillModel: 'resting', coverGeometry: 'tent' }`
— `server/src/candle-spread/index.js:169`

## Intent

The control. One simple single-timeframe price-action signal, and the cheapest, most conservative
cover geometry (a tent that shares the position's short strike, forming a butterfly). v0 exists so
v1/v2 (geometry) and v3 (covering policy) can each be read as a one-variable A/B against it, and so
the multi-timeframe lineage (v4-v9) has a naive baseline to beat. Stated at `index.js:147-168`:
"v0 KEEPS the instant tent deliberately: it is the control the other three are read against, and
v0-vs-v1 is a clean A/B of the POLICY with geometry held constant."

## Open signal

Timeframe: **15m closes only** (`at15`, `index.js:63` — intra-15m bars return a no-op).

`classicSignal`, `server/src/candle-spread/signals/classic-signal.js:7-24`:

| Condition | Action |
|---|---|
| 15m candle is green (`close >= open`) **and** `high > prior 15m high` | open **bull** (call debit spread) |
| 15m candle is red **and** `low < prior 15m low` | open **bear** (put debit spread) |
| no prior 15m bar | no open |

No Bollinger gate, no confluence gate. Continuation only: the candle must both close in the
direction *and* extend the prior bar's extreme.

> Note: `spread-logic.classifyOpen` (`spread-logic.js:33-47`) implements the same rule plus a
> first-candle-of-day Bollinger fallback, but it is only reached in **non-ported** mode
> (`trader.js:587,614`). Every family in `FAMILIES` supplies a `signalFn`, so `classifyOpen` is not
> on any current family's path.

## Cover signal

Three triggers can place a cover; all rest at a limit and fill only when the real mark reaches it.

| Trigger | Condition | Order placed | Fills |
|---|---|---|---|
| **continuous** (dominant) | every 5m bar, every uncovered position with no cover working. v0 is **unarmed**, so in practice this is the bar the position opened. | immediately, at `W − openCost − 0.25×W` | when the real mark ≤ that target |
| **reversal** | `classicSignal.cover` fires (see below), on positions with no cover working | at `W − openCost` | same resting model |
| **lock** (cover-to-continue) | a new open would push the projected book floor past `lossMax`; lock the deepest-ITM winners marking ≥ `0.65 × W` | at `W − openCost` | same |

`classicSignal`'s cover condition (`classic-signal.js:12-16`):
- holding **bull**, current 15m candle is red **and did NOT make a new high** → cover
- holding **bear**, current 15m candle is green **and did NOT make a new low** → cover

i.e. the trend "failed to extend". A red candle that still broke the prior high does **not** cover.

Geometry of the cover: `coverGeometry: 'tent'` — the cover's short leg sits **at the position's own
short strike** (`spread-logic.coverShortFor`, `spread-logic.js:186-194`). Open + cover form a
butterfly peaked at that strike: cheapest cover, largest locked floor, least terminal upside.

## Trend / reversal recognition

Purely single-bar, single-timeframe:
- **Direction** = the sign of `close − open` on the 15m candle.
- **Trend intact** = the candle also extended the prior bar's high (bull) or low (bear).
- **Reversal** = an opposite-colour candle that failed to extend the prior extreme.

There is no midline, no EMA, no multi-timeframe context, and no notion of a structural trend. The
comment at `classic-signal.js:2-6` frames this as the deliberate simplicity: "the simple baseline the
multi-TF lineage (v4-v9) was built to beat; it clusters its worst days on DIFFERENT dates, so it
diversifies."

Other measured results:
- **The classic signal is a genuine diversifier**, not just a weak baseline — its worst days cluster
  on different dates from the multi-TF lineage (`classic-signal.js:5`).
- **v0-v3 came out identical to the dollar** before 2026-09-05, because continuous covering
  overrode all four cover selectors (`index.js:149-151`).
- `openNeverOtm` on v0-10: **+$737** over 765 days, zero extra skipped opens (experiments log,
  2026-09-09).
- Live 2026-09-08: v0/v1/v2 produced **identical cover legs on 71% of positions** (roadmap).

## Open questions / suspected drift

1. **CONFIRMED — covering at birth defeats the whole v0-v3 experiment.** v0's "instant tent" is
   labelled the deliberate control, but because the cover is chosen while the underlying is still AT
   the short strike, the three geometries collapse onto the same strike. The control is fine; the
   *comparison* is not (see README drift #1/#2).
2. **CONFIRMED — the `coverSelector` axis is dead.** All of v0-v3 are `'fixed'`, and `selectCovers`
   is only reached from the reversal path, which continuous covering pre-empts (`trader.js:708-712`).
   `greedy` and `joint` are unreachable from any current family.
3. **Doc drift.** The experiments-log lineage table's v0 ("fixed-cap 0.525×width, optimistic instant
   fill") no longer describes this family at all.
4. **Intent not documented:** why `minLockFrac` is 0.25 for v0-v3 specifically. The code says it was
   *not swept* for the classic group and 0.25 is "the safest single value" (`index.js:279`) — that is
   a stated non-reason, so treat 0.25 as unvalidated for this family.
