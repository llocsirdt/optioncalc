# v2 — "classic at-money"

`{ key: 'v2', label: 'classic at-money', signalFn: at15(classicSignal), signalCfg: {}, coverSelector: 'fixed', coverFillModel: 'resting', coverGeometry: 'underlying' }`
— `server/src/candle-spread/index.js:171`

## Intent

The far end of the cover-geometry axis: put the cover's short leg **at the money** rather than at the
covered position's short strike. Widest tent, most terminal potential, dearest cover — and, uniquely
among v0-v3, a geometry that **can push open + cover past the width and forfeit the guaranteed
floor entirely**. `index.js:158-161`: "that is the trade being measured", and `spread-logic.js:181-184`
repeats it: "the one that can push open+cover past the width, forfeiting the guaranteed floor. That is
the trade being tested, not a mistake."

## Open signal

Identical to v0/v1. `classicSignal` at 15m closes only (`signals/classic-signal.js:7-24`):
green + new high → **bull**; red + new low → **bear**.

## Cover signal

Trigger conditions identical to v0 — see the shared trigger table in [README.md](README.md).

Geometry (`coverShortFor('underlying', …)`, `spread-logic.js:186-194`):

```
coverShort = grid(underlying)
```
clamped so it never moves backward past the position's own short strike. Legs from
`coverLegsAtShort` (`spread-logic.js:199-204`).

Timing is the same resting model: continuous covers rest at `W − openCost − 0.25×W`, reversal and
lock covers at `W − openCost`, filling only when the real mark reaches the limit.

## Trend / reversal recognition

Identical to v0 — single 15m candle direction plus the prior-extreme break. No structural trend.

## Open questions / suspected drift

1. **CONFIRMED — same as v1: instant covering collapses the axis.** 71% of live 2026-09-08 positions
   had identical legs across v0/v1/v2. See [README.md](README.md#continuous-cover--the-confirmed-misinterpretation).
2. **The floor guarantee is genuinely optional for this family and nothing enforces awareness of
   that.** `spread-logic.js:139-149` states the guaranteed-floor formula
   (`W − openDebit − coverDebit`) "holds for every candidate" for the *candidate* cover set — but the
   `'underlying'` geometry is explicitly documented as able to break it. The governor's floor
   projection is what actually catches this; there is no v2-specific guard, and no documented
   decision about whether one is wanted.
3. **Doc drift.** The experiments-log lineage table defines v2 as "joint cover GEOMETRY" (a
   *selector*). Superseded by the current `FAMILIES` definition but never corrected in the log.
4. **Intent not documented:** whether "at the underlying" should mean the *pricing* underlying (NDX,
   which the code uses — `trader.js:621`) or the *signal* underlying (NQ). The code is consistent
   with the foundational NQ-signals/NDX-pricing rule, but no note states this was a decision for
   cover geometry specifically.
