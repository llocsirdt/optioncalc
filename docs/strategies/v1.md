# v1 — "classic halfway"

`{ key: 'v1', label: 'classic halfway', signalFn: at15(classicSignal), signalCfg: {}, coverSelector: 'fixed', coverFillModel: 'resting', coverGeometry: 'halfway' }`
— `server/src/candle-spread/index.js:202`

Shared machinery: [README.md](README.md#shared-machinery-read-this-before-any-family-file). Triggers and
mechanisms: [signals.md](signals.md).

## Intent

Measure the **cover-geometry axis**: instead of pinning the offsetting spread to the position's own short
strike, walk it halfway toward the underlying. Open + cover then form a **condor** — a plateau rather than
a peak — trading some locked floor for a wider region that pays. Signal identical to v0 so the only
variable is where the cover sits (`index.js:189-192`, `spread-logic.js:186-201`).

## Open signal

Identical to v0: `classicSignal` at 15m closes only (`signals/classic-signal.js:7-24`, `at15` at
`index.js:95`) — green 15m candle **and** new high → **bull**; red **and** new low → **bear**. Signal on
/NQ, pricing on NDX, strikes by placement G.

## Cover signal

Trigger conditions and order life identical to v0 — see [v0.md](v0.md#cover-signal).

**What differs is the geometry, and only where it is read.** `coverShortFor('halfway', …)`,
`spread-logic.js:186-201`:

```
coverShort = grid((positionShortStrike + underlying) / 2)
```
clamped so the cover never moves backward past the position's own short strike (bull: `max`, bear: `min`). The
underlying is NDX at cover-placement time. It is honoured by:
- **10W continuous covers** — `selectCoverGeometric` (`trader.js:2952`);
- **signal (reversal) covers at every width** — `selectCoverFixed` (`trader.js:2912`).

At **20/40W** the continuous cover's strike is chosen by the cover range (`pickCoverK`), which ignores
`coverGeometry` — so v1-20/v1-40 behave as v0-20/v0-40 apart from the rare signal cover.

## Trend / reversal recognition

Identical to v0 — single 15m candle, close-vs-open direction, prior-extreme break as the trend-intact
test. No structural trend model.

## Open questions / discrepancies

1. **The geometry axis is a 10W-only test now.** The cover range (2026-10-13) superseded `coverGeometry` for
   continuous covers at 20/40W; the `FAMILIES` comment (`index.js:189-192`) and `family-about.js` still describe
   halfway as v1's cover at every width. Whether v1-20/v1-40 should keep a slot is undecided.
2. **Backtest reversal covers ignore geometry** unless `coverGeometryOnReversal` (set by nothing,
   `backtest-v6-5m.js:1887`); live reversal covers honour it. Small while continuous covering starves the
   reversal path.
3. **Intent not documented:** whether "halfway" should be measured from the underlying at cover time or at open
   time. The code uses cover time, which for a continuous cover is the first pass after the fill.
4. **Stale watchlist:** `WATCHLIST` (`index.js:52-55`) still defaults to `v1-10,v2-10,v6-10` and its comment
   calls them the "no ladder" control cells; they carry the ladder since 2026-10-09.
