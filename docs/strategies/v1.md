# v1 — "classic halfway"

`{ key: 'v1', label: 'classic halfway', signalFn: at15(classicSignal), signalCfg: {}, coverSelector: 'fixed', coverFillModel: 'resting', coverGeometry: 'halfway' }`
— `server/src/candle-spread/index.js:170`

## Intent

Measure the **cover-geometry axis**: what happens if the offsetting spread is not pinned to the
position's own short strike but walked halfway toward the underlying. Open + cover then form a
**condor** — a plateau rather than a peak — trading some locked floor for a wider region that pays.
Signal is held identical to v0 so the only variable is where the cover sits
(`index.js:157-160`, `spread-logic.js:174-184`).

## Open signal

Identical to v0. `classicSignal` at 15m closes only (`signals/classic-signal.js:7-24`, `at15` at
`index.js:63`):
- green 15m candle **and** `high > prior high` → **bull**
- red 15m candle **and** `low < prior low` → **bear**

## Cover signal

Trigger conditions identical to v0 (continuous every bar / classic reversal / cover-to-continue lock)
— see [v0.md](v0.md#cover-signal) and the shared trigger table in [README.md](README.md).

**What differs is the geometry.** `coverShortFor('halfway', …)`, `spread-logic.js:186-194`:

```
coverShort = grid((positionShortStrike + underlying) / 2)
```
clamped so the cover never moves backward past the position's own short strike. Legs are then
`coverLegsAtShort` (`spread-logic.js:199-204`): a covered bull is offset by a put spread short at
`coverShort`, long at `coverShort + W`; mirror for a bear.

Order placement/fill timing is the same resting model as v0 — placed at
`W − openCost − 0.25×W` for continuous covers, `W − openCost` for reversal and lock covers, filled
only when the real mark reaches it.

## Trend / reversal recognition

Identical to v0 — single 15m candle, close-vs-open direction, prior-extreme break as the
trend-intact test. No structural trend model.

## Distinguishing config

| Flag | v1 | v0 |
|---|---|---|
| `coverGeometry` | **`'halfway'`** | `'tent'` |
| everything else | same | same |

`continuousCoverMinLockFrac` 0.25 (`index.js:282`). No arming knobs — v1 covers instantly, like v0.

## Open questions / suspected drift

1. **CONFIRMED — the geometry this family exists to test barely expresses.** Live 2026-09-08, 71% of
   positions got *identical* cover legs across v0/v1/v2, and v0-10 vs v1-10 daily P&L correlation was
   0.93. Cause: continuous covering picks the cover while the underlying is still AT the short
   strike, where `tent`, `halfway` and `underlying` all round to the same strike. Divergence only
   begins once price has moved — which is when the intended design would have covered. Recorded in
   the roadmap ("one strategy running under three labels 71% of the time").
2. **CONFIRMED (fixed 2026-09-09, scope-corrected) — `selectCoverFixed` ignored `coverGeometry`.**
   All of v0-v3 carry `coverSelector:'fixed'` and `selectCoverFixed` hardcoded `geometry:'tent'`. The
   defect was confined to the **reversal** path; the live continuous path calls
   `selectCoverGeometric` directly and always honoured geometry. Fixed at `trader.js:1050-1070`; the
   backtest side is behind the opt-in `coverGeometryOnReversal` flag so committed baselines
   reproduce. Experiments log, 2026-09-09.
3. **Doc drift.** The experiments-log lineage table defines v1 as "greedy cover GEOMETRY" (a
   *selector*, from `backtest-tent.js`). That is a different thing from `coverGeometry:'halfway'`.
   Two sources disagree about what v1 is.
4. **Intent not documented:** whether `halfway` should be measured from the *underlying at cover
   time* or from the underlying at *open* time. The code uses cover time, and under instant covering
   those are the same moment — which is exactly why the axis collapses.
