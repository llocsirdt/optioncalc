## Intent

**v8 = v6 signal + proactive deep-ITM covering (0.80×W) + reopen after a quick cover**, on the shared governor.
Since 2026-10-14 it is the v6 counterpart of v9 (v7 + the same two features): `index.js:1071-1073`, "so v8 = v6
+ proactive cover + reopen and v9 = v7 + the same: a readable comparison."

What changed on 2026-10-14 (user, `index.js:213-219`):
- The soft **"churn" cap** (`softCap: 3000` + `exemptTrendStack`) is **OFF**. It capped the debit on uncovered,
  not-deep-ITM positions at a flat $3,000 — the pre-governor risk layer — and, flat across widths, allowed about
  one uncovered 40W position at a time. The feature stays in `capState` (`trader.js:447-459`), backlogged.
- `proactiveCoverFrac` **0.70 → 0.80**, the same as v9.
- `reopenOnCover` turned on for every v8 variant.

Since 2026-09-07 v8 is an **experiment slot**, not a trading candidate. User's ruling: *"we want to use
those slots to see if we can tweak v6 or v7 rules to beat them."* Do not propose retiring it.

## Open signal

Identical to [v6](v6.md#open-signal) — `v6Signal` with `fiveMin: true`, every 5m bar, including
**cover-to-open-wait** (`coverToOpenWait: true` on every v8 variant).

Plus **reopen after a quick cover** (`reopenOnCover`, every v8 variant including `-unc`/`-cATM`): after a cover
fills, re-open the same side at the same strikes (or deeper ITM at no more than the price paid) while NDX is still
inside them and the 15m signal that opened it stands — full rule in [v7.md](v7.md#open-signal). **Live only**; the
backtest has no reopen.

No variant carries `softCap`, `hardCap` or `riskCap`, so `capState` never blocks an open.

## Cover signal

v6's signal covers (both sides; break-even resting tents on positions without a cover working), plus:

| Trigger | Condition | Placed |
|---|---|---|
| **proactive** | uncovered position, no cover working, spread marking ≥ **0.80 × W** | break-even resting **tent** (`selectCoverFixedMark`), note `proactive-deep-itm` (`trader.js:2310-2322`) |
| shared layer | continuous cover (10W plateau `offset1` / minLock 0.05×W; 20/40W cover range / minLock 0.20×W), ladder, stall 15 min, give-up 20 pts, governor deferral, floor raise, wings, floor offsets | README |
| **cover-to-stack** | **never fires live**: it runs only when `softCap`/`hardCap`/`riskCap` block an open (`trader.js:2478-2510`, `coverToStackFreeBudget` `:474`), and all three are null since the churn cap went off. The **backtest** still locks winners ≥ 0.65×W when the governor would block an open (`backtest-v6-5m.js` ~2064-2085; `coverToStackVsRisk` from `opts-for.js:78`) — on every governed family, not just v8 | — |

Engine order differs: the backtest runs proactive **before** continuous (`backtest-v6-5m.js:1074-1082`, a0 then
a0b); live runs it **after** continuous and the reversal step. Under unarmed continuous covering a position normally
already has a cover working by the time it marks 0.80×W in both engines, so proactive rarely places an order.

## Trend / reversal recognition

Identical to v6. `proactiveCoverFrac` is a book-state threshold on how deep in the money a position has run,
not a market read.

## Lineage

- **Inherits from:** v6 exactly (signal, cadence, cover machinery, cover-to-open-wait).
- **Changed (2026-10-14):** churn cap off, `proactiveCoverFrac` 0.70 → 0.80, `reopenOnCover` on; 2026-10-16
  `coverToOpenWait` on. The label is now `'proactive'` (these docs had it as `'risk-capped'` on 2026-10-07).
- **Earlier history:** built against v7's *old* single risk cap ("blindly stops ALL opens once uncovered debit ≥
  cap"), retired for the day-loss governor on 2026-09-04. The v8 ablation (`scripts/candle-spread/ablate-v8.js`,
  2026-09-05) found `softCap` alone was the damage and the proactive cover was not the culprit. The user's
  2026-09-05 agreed direction for the slot — the cover-GEOMETRY axis (partial/fractional covers, near-the-money
  covers on deep-ITM) — was never built as a v8 feature.

## Open questions / discrepancies

1. **In the backtest the proactive cover only costs.** Every v8 row is at or below the matching v6 row on total
   with no change in worst day or maxDD30. Whether it earns its place live — where reopen also differs — is open.
2. **Cover-to-stack is backtest-only now.** `coverToStack: true` sits on every v0-v9 variant, but live it can fire
   only behind a legacy cap that no variant has; the backtest fires it on governor blocks. A live/backtest parity
   gap on every governed family (mostly inert where continuous covers claim everything; matters most on v3).
3. **Stale comments:** `capState`'s header (`trader.js:437`) still calls the caps "v8 risk caps", and the call site
   (`trader.js:2481-2483`) says "else skip (existing v8 behavior)".
4. **The churn cap's future is backlogged** (`index.js:216-218`): the machinery stays, no variant uses it.
