## Correction to 11-05: cover-to-stack does nothing in either engine
The 11-05 entry said the backtest "still locks winners when the governor blocks an open". Wrong.
- **Live:** a governor-blocked open is skipped (`open-skip-governor`). Cover-to-stack is only wired to the old cap
  branch, and every cap has been null since 10/14. It was never ported when the governor replaced the caps (734b961,
  09-04).
- **Backtest:** `lockDeepWinners` runs on governor blocks, but it skips any position that already has a resting
  cover. Continuous cover gives every position one, so nothing is ever locked. A 250-day run with it on and off was
  byte-identical, with zero locks, even though v9-20 hit 804 governor blocks.
- **At the blocks themselves (120 days):** the deep winners the user wants locked are there (v9-20 1.85 per block,
  v7-10 1.04). Every one already has a resting cover priced below the market (v9-20 target 0.25×W vs mark 0.37×W;
  v7-10 0.42 vs 0.50).
- **User decisions:** fix it; the held open waits for the locks to fill before it is sent. The pricing rule (move
  those covers to the market when that raises the floor, total ≤ ~1.15×W?) still needs working through, so nothing is
  built yet.

## Replaying 11/05 on the new code
The user asked how to rerun 11/05 against the fallback-width code. Neither path the user floated works on its own:
- **Chain snapshots:** the 11/05 archive holds 29 per run, ±80 pts around the money on the 10-pt grid. The 25-pt
  strikes were never captured.
- **25-pt strikes in the backtest's model chain:** the user is right that 25s are always listed and the 10s are what
  goes missing. But the backtest prices any strike it asks for, and it fixes one width per run (54 places in the
  engine), so it cannot switch to 25W partway through a day.

Built instead (user's choice): `scripts/candle-spread/replay-live-day.js`, which runs the real live engine over a past
day.
- The clock is faked and Schwab is replaced by files.
- The modelled chain always lists the 25s, and lists the 10s only inside `--tens`.
- **Result for 11/05** (`data/replays/2026-11-05.md`): every tick ran. 20/40W opened 3 positions at their own width,
  then 25W/50W for the rest of the day; 10W stopped. On the old code, live made $0 on every 20W run.
- **Calibration:** model single legs price about $66 below the real snapshots on this high-vol day; 20W verticals
  about −$0.48. Read the dollar results as direction only.
